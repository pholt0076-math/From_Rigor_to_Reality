# Membership Functions: Turning Belongs-To Into Computation — Measure Theory Bridge 0.05

One of the strangest transitions in higher mathematics happens when sets stop being passive objects and become executable structure.

At first, set membership looks trivial:

x in A

Either something belongs to a set or it does not.

True or false.

But Measure Theory eventually transforms this simple idea into one of the foundational building blocks of modern analysis.

The key object is the membership function, also called the indicator function:

I_A(x)

Defined by:

I_A(x) = 1 if x in A
I_A(x) = 0 if x not in A

A set has become a function.
