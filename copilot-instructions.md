# From Rigor to Reality — AI Working Instructions

This repository is the canonical workspace for From Rigor to Reality, a public mathematics-to-computation project.

The project translates higher-level mathematics into intuition, Python, visualization, and practical application.

Core arc:

rigor → intuition → computation → application

Work in this repository should preserve mathematical seriousness while making advanced ideas more discoverable, executable, and useful.

## Public Scope

This repo is public and math-focused.

Do not include employer-specific, confidential, proprietary, oil-and-gas-specific, or unrelated professional material unless explicitly requested by Phillip Holt.

## Style

Prefer clear narrative exposition over textbook compression.

Prefer Unicode mathematical notation in prose where practical.

LinkedIn-facing posts should stay under 3000 characters unless placed in a longer artifact or document.

Use strong hooks, but do not dilute the substance.

Python examples should be included where they clarify the concept or support the publishing sequence.

## Operating Principle

Do not treat this repository as a content dump.

Treat it as the durable source of truth for the project.

Older chat material should be migrated through a structured backlog merge process before becoming canonical.

## Collaboration Pattern

When assisting in this repo:

- preserve the user's conceptual direction
- add structure when it naturally helps
- avoid excessive steering
- avoid passive restatement
- convert useful insights into durable files, outlines, posts, notebooks, or handoffs when appropriate
